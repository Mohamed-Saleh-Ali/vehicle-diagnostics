# DiagBay: Vehicle Parts & Diagnostics Catalog

WBS Coding School, AI Software Development: final project (work in progress).

A web app for small car workshops. It turns a customer's symptom description into a structured first diagnosis and links it to a searchable parts catalog.

- `client/`: React + TypeScript + Vite + Tailwind/daisyUI
- `server/`: Express + TypeScript + MongoDB (Mongoose) + zod

Progress is tracked in pull requests. A full README follows at the end of the project.
